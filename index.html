WHY WEBMCP

WebMCP is not decoration here. It is the interface that makes the agent path explicit enough to verify and govern.

NATIVE WEBMCP + MISSION CONTROL

Call explicit tools under a Goal Contract

  • Typed schemas and tool descriptions
  • Shared state between agent and visible UI
  • Machine-readable verification and recovery
  • Commit gate returns HUMAN_APPROVAL_REQUIRED

IMPLEMENTATION EVIDENCE

Open source, inspectable, and native.

The same application logic powers both the human UI and the WebMCP tool surface. The implementation uses native document.modelContext.registerTool(); no MCP server shim is required for this demo.
